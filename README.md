# Эхо времени — самостоятельный сайт

«Эхо времени» отделён от сайта SwordLand на уровне исходного проекта. Исходная страница находится в корне ветки как `index.html`; её HTML, стили, скрипты, галерея, озвучка и тестирование не изменены.

## Отдельная публикация на GitHub Pages

1. Создайте новый **публичный** репозиторий GitHub (например `echo-time`) в аккаунте, на котором вы хотите размещать сайт.
2. Скопируйте `index.html` и `.nojekyll` из этой ветки в корень нового репозитория. Можно скачать ZIP этой ветки и загрузить файлы через сайт GitHub.
3. Откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main`, папку **/(root)**, затем сохраните.
4. Адрес обычно будет `https://<владелец>.github.io/echo-time/`, если имя репозитория `echo-time`. Точный адрес появится в настройках Pages после публикации.
5. Если нужен собственный домен, задайте его в **Settings → Pages → Custom domain** и настройте DNS у регистратора.

**Важно:** сторонние фото/аудиофайлы могут загружаться с внешних ресурсов, так что для их работы нужен интернет и доступность этих ресурсов. Первоначальный сайт `swordland.ru/echo-time/` пока оставлен без изменений; удалять его/делать редирект следует после запуска нового адреса.
